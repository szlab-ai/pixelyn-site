PIXELYN / APPLE TV

Privacy

The same privacy information you’ll find in the app.

Last updated: October 27, 2026

No data collection

Pixelyn does not collect or upload any data. There are no accounts, ads, analytics or third-party SDKs. The app does not connect to the internet.

Preferences stay on your Apple TV

Five preferences are saved only on this Apple TV: display name, last tab, last pattern for each test, Auto-Advance and language. Deleting the app removes them all. Reset Settings clears your choices, turns Auto-Advance on and follows the system language, keeping you on the Settings tab.

Display information

Screen information is read from the system each time you open the app. It is not saved or sent anywhere.

About this website

This public website is hosted on GitHub Pages. Opening a website is separate from using the offline app. We add no analytics, advertising, forms or cookies to this site. GitHub may process technical request information under its own privacy statement. GitHub Privacy Statement
